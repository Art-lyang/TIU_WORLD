# TIU AI GM 용어 매핑

> 작성일: 2026-04-30  
> 목적: 원본 AI GM 문서의 용어를 TIU 정본 캐논에 맞게 재해석한다.

## 핵심 매핑

| 원본 용어 | 원본 의미 | TIU 적용 의미 | 처리 |
|---|---|---|---|
| 카룬탈 | 시간/공간/물질 인프라 | 고대 경계/봉합/공간 인식 규칙과 연결된 비인간 지식층 | 이름 직접 사용 주의 |
| 오라클 | 미래/진실/운명 관측자 | ORACLE. 장기 운용 시스템, 예측/분류/은폐/기폭제 | 정의 수정 필수 |
| 관측자 | 룰 위반 집행자 | Observer. 분기 고정, GRANT, 세션 왜곡, ORACLE 상위 존재 | 처벌자 표현 약화 |
| 관측자 시선 | 위반 단계 | Observer Attention. 세션 왜곡/분기 축소/GRANT 제한 지표 | 유지 가능 |
| 카룬탈 균형 | 세계 균형 수치 | Boundary Stability. 공간/사건/인과 안정성 | 이름 변경 추천 |
| 오라클 인식 | 오라클 주목도 | ORACLE Classification. ORACLE이 플레이어를 어떻게 분류하는지 | 이름 변경 추천 |
| 세계의 헌법 | 절대 룰 | AI GM 운영 규칙. 정본 캐논이 아니라 게임 운영 레이어 | 제목 보정 |
| 먼치킨 방어 | OP 차단 | 세계관 일관성 보호 장치 | 유지 |
| 금지 능력 | 플레이어 사용 불가 | 시작 캐릭터/일반 플레이 제한. 예외는 정본 NPC/사건 전용 | 유지하되 예외 명시 |

## 추천 상태 변수

원본 상태값:

```text
관측자 시선
카룬탈 균형
오라클 인식
```

TIU 추천 상태값:

```text
Observer Attention      : 평온 / 주목 / 간섭 / 왜곡 / 단절
ORACLE Classification   : 미분류 / 관찰 / 유용 / 위험 / 제거대상
Boundary Stability      : 안정 / 흔들림 / 균열 / 붕괴 / 봉합불가
Disclosure Level        : PUBLIC / RESTRICTED / OBSERVER / PRIVATE
```

## 표현 보정 예시

| 피해야 할 표현 | TIU식 표현 |
|---|---|
| "오라클은 모든 미래를 본다" | "ORACLE은 가능한 결과를 모델링하지만, 최심부 원인에는 접근하지 못한다" |
| "관측자가 룰 위반자를 처벌한다" | "Observer의 관측이 분기를 고정하고, 세션의 선택지를 줄인다" |
| "카룬탈이 시간을 막는다" | "해당 시도는 경계층에서 무효화되고, 주변 기록이 어긋난다" |
| "신화의 신들도 카룬탈 아래 있다" | "신화권의 신들은 고대 사건을 문화권별로 해석한 이름일 수 있다" |
| "플레이어는 오라클을 잠시 빌린다" | "플레이어는 ORACLE의 낮은 등급 예측 파편을 우연히 열람한다" |
