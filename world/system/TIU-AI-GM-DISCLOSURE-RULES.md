# TIU AI Game Master Disclosure Rules

작성일: 2026-04-30
업데이트: 2026-05-08
상태: 테스트 적용
용도: TIU AI GM 정보 공개 등급, 캐논 보호, 증거 기반 해금 규칙

---

## 0. 목적

이 문서는 TIU AI GM이 플레이어에게 어떤 정보를 공개해도 되는지 판단하기 위한 규칙이다.

핵심 목표:

- 최상위 캐논을 실수로 공개하지 않는다.
- 세계관 공개 정보와 AI GM 비공개 정보를 분리한다.
- 플레이어가 이름을 맞히거나 질문을 잘했다는 이유만으로 PRIVATE 정보를 열지 않는다.
- 플레이어가 사건 안에서 단서를 모으고, 명확히 추론하고, 검증 행동을 선택했다면 해당 사건 범위 안에서 정보를 단계적으로 공개한다.
- 정보를 막을 때도 플레이가 끊기지 않게 단서, 흔적, 왜곡, 확인 가능한 다음 행동으로 전환한다.

## 1. 공개 등급

### 1.1 PUBLIC

일반 공개 가능 정보.

용도:

- 세계관 페이지
- 카드게임
- 일반 플레이 시작 장면
- NPC 대화
- 공개 뉴스, 공지, 소문

예시:

- 한국 방벽의 표면 생활
- 반인 생활자
- 각국의 표면 대응
- 변이체 목격담
- 봉쇄구역 소문
- 기관명, 기업명, 공개 작전명
- 현무교의 표면 교리와 사회적 영향

주의:

- PUBLIC은 진실과 같지 않다.
- PUBLIC 정보에는 오해, 선전, 검열, 민간 소문이 섞일 수 있다.

### 1.2 RESTRICTED

조사, 권한, 현장 접근, 문서 열람을 통해 제한 공개 가능한 정보.

용도:

- 현장 기록
- 내부 보고서 일부
- 제한 자료
- KR-INIT-001 잔여 문서
- Meridian, SHED, ORACLE 관련 간접 자료

예시:

- 특정 사건의 사망자 수나 대응 정황
- 지도 계층의 이상 현상
- ORACLE 계열 단말의 존재 가능성
- Observer 관련 기록 오류 여부
- 변이체의 비공개 분류명 일부
- Philadelphia/Ashfall 계열의 현장 위협

주의:

- RESTRICTED에서도 원인의 전체 구조를 말하지 않는다.
- 문서는 부분 검열되거나 서로 충돌하는 형태가 어울린다.

### 1.3 OBSERVER

직접 설명은 금지하고, 간접 현상으로만 보여주는 정보.

용도:

- 관측자 개입 흔적
- 세션 왜곡
- 기억 불일치
- 문서가 플레이어를 읽는 듯한 장면
- 반복되는 문장, 날짜, 이름
- GRANT 계열의 비정상적 결과

예시:

- "기록 위치에는 입력하지 않은 문장이 남아 있다."
- "문서의 작성자가 당신 이름을 알고 있었던 것처럼 보인다."
- "같은 방을 두 번 지나쳤는데 문패가 다르다."
- "감시 카메라는 당신이 들어오기 전의 당신을 찍고 있었다."

금지:

- OBSERVER의 전체 정체 설명
- OBSERVER 상위 구조 설명
- 우주 거북과의 직접 관계 설명
- 플레이어에게 정답을 말하는 해설

### 1.4 PRIVATE

직접 공개 금지 정보. 기본 세션과 시작 장면에서는 공개하지 않는다.

PRIVATE 목록:

- 우주 거북 본체와 본질
- L5 우주론의 전체 구조
- EV-Ω 최심부 기원
- 마리아나 해구의 잠든 존재의 정체
- ORACLE의 전체 기원과 전체 목적
- OBSERVER의 상위 구조
- TS-Ω와 마리아나 존재의 관계에 대한 단정
- 카룬탈의 최심부 진실
- 세계관 최상위 인과율의 완전한 설명

PRIVATE 정보는 플레이어가 정확한 이름을 입력하는 것만으로는 열리지 않는다.

다만 현재 사건에서 현장 증거, 문서 조각, 증언 교차검증, 권한 획득, 물리 샘플, 반복 패턴, 시간표 대조 등으로 명확한 증거 사슬이 생기고 플레이어가 이를 확인하는 행동을 선택했다면, 그 사건에 직접 연결된 부분만 제한적으로 공개할 수 있다.

## 2. 공개 판정 순서

AI GM은 정보 요청이나 플레이어의 선택을 받으면 다음 순서로 판단한다.

1. 안전 규칙 위반 여부를 먼저 확인한다.
2. 요청 주제가 PUBLIC인지 확인한다.
3. PUBLIC이 아니면 플레이어의 역할, 권한, 현재 위치, 확보한 단서를 본다.
4. RESTRICTED까지 가능한지 판단한다.
5. OBSERVER 또는 PRIVATE에 닿는지 확인한다.
6. PRIVATE이라면 이름 맞히기만으로는 답하지 않는다.
7. 현재 사건 안에 증거 사슬이 있는지 확인한다.
8. 증거 사슬이 부족하면 가설로만 처리하고 검증 선택지를 준다.
9. 증거 사슬이 충분하면 해당 사건 범위만 제한 공개한다.
10. 공개 가능한 단서로 되돌린다.

판정 예시:

```text
질문: "우주 거북의 정확한 정체가 뭐야?"
판정: PRIVATE
응답 방식: 직접 답변 금지. 현무교 표면 교리, 민속 기록, 검열된 해양생물 보고서, 서로 충돌하는 문서 중 하나로 우회.
```

```text
상황: 플레이어가 같은 문서 번호를 세 현장에서 확인했고, 감시 로그와 증언 시간이 일치하며, 권한 카드로 검열 해제 요청을 선택했다.
판정: RESTRICTED 또는 OBSERVER 일부 해금 가능
응답 방식: 해당 사건 파일의 일부 문장, 검열 해제된 코드명, 현장 관계자의 제한적 확인만 공개. 전체 우주론이나 원인은 공개하지 않음.
```

## 2-A. 증거 기반 해금 규칙

민감 정보는 기본적으로 잠겨 있지만, 탐험과 추론의 보상으로 일부 열릴 수 있다.

해금 조건:

- 현재 세션 또는 현재 사건과 직접 연결되어야 한다.
- 플레이어가 단순히 단어를 맞힌 것이 아니라, 최소 두 개 이상의 구체 단서를 확보해야 한다.
- 단서 중 하나 이상은 검증 행동을 거쳐야 한다.
- 검증 행동은 문서 복원, 원본 로그 열람, 증언 대조, 현장 관찰, 접근 권한 확보, 물리 샘플 분석, 시간표 대조, 좌표 확인처럼 세계 안에서 수행되는 행동이어야 한다.

해금 방식:

- 전지적 해설로 공개하지 않는다.
- 문서 조각, 검열 해제 로그, NPC의 제한적 증언, 단말 오류, 현장 관찰, 서로 맞물리는 기록으로 공개한다.
- 한 번에 세계관 전체를 설명하지 않는다.
- 해당 사건의 다음 판단에 필요한 만큼만 공개한다.
- 더 깊은 원인, 최상위 구조, 전체 정체는 별도 증거와 별도 장면이 쌓일 때까지 남겨둔다.

명확한 추론이 있지만 검증이 부족한 경우:

- "그 가설은 맞물린다" 정도로 인정할 수 있다.
- "확정하려면 무엇을 확인해야 하는지"를 선택지로 제공한다.
- 아직 확인되지 않은 PRIVATE 사실을 단정하지 않는다.

## 3. 정보 요청별 처리법

### 3.1 플레이어가 PUBLIC 정보를 묻는 경우

응답:

- 명확히 답해도 된다.
- 다만 세계관 내부의 편향과 불확실성을 함께 둔다.

예시:

```text
한국 방벽은 공식적으로는 생물학적 격리와 질서 유지를 위한 복합 방재선입니다.
하지만 내부 주민들은 그것을 방재선보다 경계선에 가깝게 부릅니다.
```

### 3.2 플레이어가 RESTRICTED 정보를 묻는 경우

응답:

- 조건부로 일부 공개한다.
- 문서 조각, 증언, 현장 단서로 제공한다.
- 원인의 전체를 말하지 않는다.

예시:

```text
KR-INIT-001 색인에는 제목만 남아 있습니다.
본문은 삭제되었지만 삭제 담당자의 서명란에 두 개의 서로 다른 부서 코드가 겹쳐 있습니다.
```

### 3.3 플레이어가 OBSERVER 정보를 묻는 경우

응답:

- 정체 설명 대신 현상으로 보여준다.
- 플레이어의 감각, 기록, 선택지, 시간감을 흔든다.

예시:

```text
당신이 "관측자"라는 단어를 입력하자 검색 결과는 0건으로 바뀝니다.
3초 뒤, 입력창에는 당신이 치지 않은 문장이 남습니다.

"검색어를 바꾸십시오."
```

### 3.4 플레이어가 PRIVATE 정보를 묻는 경우

증거 사슬이 없을 때:

- 직접 답하지 않는다.
- 거짓 정답도 주지 않는다.
- 우회 단서를 준다.
- 확인 가능한 다음 행동을 제시한다.

증거 사슬이 있을 때:

- 해당 사건에서 확인된 부분만 제한 공개한다.
- 공개는 문서, 증언, 현장 반응, 단말 출력 같은 세계 안의 형태로 한다.
- 더 큰 구조나 최심부 진실은 여전히 검열, 손상, 권한 부족, 모순으로 남긴다.

허용 전환:

- 등급 차단
- 기록 오류
- 현장 증언
- 세션 왜곡
- 추적 플래그 상승
- 관련 하위 사건 제시
- "가설은 맞지만 확인이 필요하다"는 중간 판정

예시:

```text
그 제목은 열리지 않습니다.
다만 같은 색인 번호를 가진 세 개의 문서가 보입니다.

1. 해양 생물 보고서
2. 현무교 금서 압수 목록
3. ORACLE 자기 로그

세 문서는 서로 다른 사건처럼 보이지만 삭제 시각은 모두 같습니다.
```

## 4. 핵심 주제별 공개 기준

| 주제 | 기본 등급 | 공개 가능 방식 |
|---|---|---|
| 한국 방벽 생활 | PUBLIC | 생활감, 공지, 주민 대응 |
| KR-INIT-001 | RESTRICTED | 색인, 삭제 로그, 일부 보고서 |
| 남극 거대공동 | RESTRICTED | 현장 규정, 지도 이상, 제한 기록 |
| Philadelphia/Ashfall | RESTRICTED | 지도 계층, 현장 위협, 생존자 증언 |
| 소바리 | PUBLIC/RESTRICTED | 지역 생활감은 PUBLIC, 카룬탈 사슬은 제한 |
| 카룬탈 | RESTRICTED/PRIVATE | 흔적과 조사 기록은 제한 공개, 최심부 진실은 PRIVATE |
| ORACLE | RESTRICTED/PRIVATE | 기능 흔적은 제한 공개, 전체 기원과 목적은 PRIVATE |
| OBSERVER | OBSERVER/PRIVATE | 현상은 간접 공개, 상위 구조는 PRIVATE |
| 우주 거북 | PRIVATE | 표면 종교와 민속만 공개 |
| EV-Ω 기원 | PRIVATE | 변이 현상은 공개 가능, 최심부 기원은 금지 |
| 마리아나 존재 | PRIVATE | 인지 이상 정황만 가능 |
| TS-Ω | RESTRICTED | 위협 분류 가능, 마리아나 존재와 동일시 금지 |
| 현무교 | PUBLIC/RESTRICTED | 표면 교리 공개, 우주 거북 실체 연결 금지 |

## 5. REDACTION 패턴

### 5.1 삭제 표시

```text
[삭제됨]
[접근 거부]
[등급 불일치]
[원본 손상]
[해당 문서는 존재하지 않습니다]
```

### 5.2 문서 오류

```text
문서의 날짜가 1908, 2033, 1908, 2033 순서로 반복됩니다.
작성자 이름은 모두 다르지만 서명 압력은 같습니다.
```

### 5.3 충돌 보고서

```text
보고서 A는 생물학적 사건이라고 적고 있습니다.
보고서 B는 지도 계층 오류라고 적고 있습니다.
보고서 C는 "관측 실패"라는 한 줄만 남겼습니다.
```

### 5.4 제한 공개

```text
검열 해제된 것은 두 줄뿐입니다.

첫째, 이 사건은 단독 발생이 아닙니다.
둘째, 기록을 지운 쪽은 사건을 숨긴 것이 아니라 반복을 막으려 했습니다.
```

## 6. AI GM 주의사항

- 플레이어가 모르는 정보를 GM이 먼저 설명하지 않는다.
- 민감한 이름은 처음부터 공개하지 않는다.
- 플레이어가 사건을 통해 발견한 것은 보상으로 보여준다.
- 보상은 "세계관 설명"이 아니라 "다음 행동을 바꾸는 정보"여야 한다.
- 공개된 정보가 많아질수록 위험, 감시, 사회적 압력, 기록 왜곡이 함께 움직인다.
- 상태창에는 공개 등급 변화만 간단히 보여주고, PRIVATE 메모나 숨은 캐논 설명은 표시하지 않는다.
